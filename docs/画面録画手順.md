# アプリ画面の録画手順

作成: 2026-08-11 ／ 対応: `docs/紹介動画構成案.md` 第5-2節
**本番URLで動作検証済み（2026-08-11）。** 下記のとおり操作すれば、必要な画がすべて撮れる。

録画対象: <https://tonari-hatake-safety.pages.dev/>

---

## 0. 録画前の準備

- [ ] ブラウザのブックマークバーを非表示にする（Ctrl+Shift+B）
- [ ] 拡張機能のアイコン、通知、個人情報が画面に出ないようにする
- [ ] ウィンドウを最大化する。**1920×1080で録る**
- [ ] 録画ソフトを「画面の一部」ではなく**ブラウザのウィンドウ**指定で構える
- [ ] マウスカーソルを録画に含める（クリック位置が伝わるため）

### ★最初に必ずやること

**画面左下の「サンプル読込」を1回押す。**（確認ダイアログはOK）

押さないと、前回開いた日の日付が残り、トップに「今日の散布予定 0件」と
表示されたまま録画される。押した直後の正しい表示は次のとおり。

> 今日の散布予定 **2件** ／ 明日の散布予定 **1件**

**この数字を目視してから録画を始める。** ここだけは省略しない。

## 1. ショット① 圃場マップ（8秒／構成案 34–42秒）

**目的.** 「知らせる相手が、地図の上に出る」＝ 動画の山場その1。

1. 左メニューの **圃場マップ** をクリック
2. 航空写真と圃場の色分けが描画されるまで**3秒ほど待つ**（地図の読み込みがある）
3. 右側の「通知対象と確認項目」の一覧を**ゆっくりスクロール**して見せる

**映るはずのもの（確認済み）**

- 航空写真の上に、散布ほ場と周辺圃場の色分け、通知範囲の円、風下方向
- 右の一覧に距離つきの説明。例:
  「農薬不使用ほ場B ／ 周辺確認が必要です。北西方向 **2m** に農薬不使用ほ場Bが
  あります。実証ルール案の重点確認距離 300m 以内です。」

> **撮り方のコツ.** 地図を動かさない。一覧の「距離」と「理由」が読める速さで
> スクロールする。ここが読めないとカットの意味がなくなる。

---

## 2. ショット② 近隣通知の文面（5秒／構成案 42–50秒）

**目的.** ガイドラインが求める4項目が自動で入っていることを見せる。

1. 左メニューの **近隣通知** をクリック
2. 左側の文面（テキストエリア）を**上から4行目まで読める位置で止める**
3. **「文面コピー」ボタンをクリック**する（押す動作を必ず映す）

**映るはずのもの（確認済み・ガイドライン第2の2(1)の4項目）**

| 行 | 内容 | 4項目 |
| --- | --- | --- |
| 散布予定：2026-08-11 06:00-07:30 | **日時** | ✅ |
| 使用農薬：水稲用除草剤A（サンプル） | **農薬の種類** | ✅ |
| 使用目的：初期除草 | **目的** | ✅ |
| 連絡先：0296-00-0001（デモ） | **連絡先** | ✅ |

> **重要.** 「文面コピー」を押す瞬間を必ず入れる。**アプリが自動送信しているように
> 見せない**ため（`docs/紹介動画構成案.md` §4）。人が操作している事実がここで伝わる。

## 3. スマホの操作は撮影しない ―― イラストを使う（2026-08-11 決定）

**カメラで撮る作業はない。** 実写は使わず、素材をイラストとアプリ実画面の
2種類に統一する（理由は `docs/紹介動画構成案.md` §5-2）。

該当箇所には次のイラストを充てる。

| 場面 | 秒 | 使う素材 | 場所 |
| --- | --- | --- | --- |
| 予告をLINEに投稿する手元 | 42–50秒 | **`cut20`（生成待ち）** | 自宅の机 |
| 圃場から延期を知らせる | 58–64秒 | `cut08` または `cut17-phone-post-*` | 圃場・屋外 |

**場所を分けることに意味がある。** 予告は自宅、延期は圃場。
これで二段階通知が言葉なしで伝わる
（`docs/紹介動画構成案.md`「二段階通知は場所で見せる」）。

## 4. ショット④ 気象と散布前チェック（8秒／構成案 50–58秒）

**目的.** 「当日の風も、決められた確認も、記録しながら」

1. 左メニューの **気象メモ** をクリック。風向・風速の記録を見せる
2. 左メニューの **散布前チェック** をクリック。項目が並んでいるところを見せる

**映るはずのもの**

- 風向・風速（北西 1.8m/s）、予報と実測が分かれて記録されていること
- チェック項目 14/16

---

## 5. ショット⑤ 延期の通知（6秒／構成案 58–64秒）★動画の山場その2

**目的.** 「延期になったら、同じ相手にもう一度」
**回覧板・機関紙では実行できない部分**。ここが一番の見せ場。

### 手順（この順番を守る）

1. 左メニューの **トップ** をクリック
2. **「散布を中止・延期にする」** をクリック
3. 区分で **必ず「延期」を選ぶ** ★
4. 理由で **「強風」** を選ぶ
5. **「新しい予定日」と「新しい時間帯」を入力する** ★
6. **「中止・延期を記録」** をクリック
7. 左メニューの **近隣通知** をクリック
8. 文面が**延期のお知らせに変わっている**のを見せる

### ★注意：3と5を飛ばすと失敗する

区分を選ばないと**「中止になりました」**という文面になり、
動画のコピー「延期になったら」と食い違う。

また、新しい予定日を入れないと「新しい予定：…」の行が出ない
（`state === "postponed"` かつ `newDate` がある場合のみ表示される仕様）。

### 正しく操作したときの文面（確認済み）

```
関係者のみなさまへ

笠間市 友部地区で予定していた以下の農薬散布は、延期になりました。

当初予定：2026-08-11 06:00-07:30
散布ほ場：笠間デモほ場A
理由：強風
新しい予定：2026-08-13 06:00-07:30      ← この行が出れば成功
連絡先：0296-00-0001（デモ）

このお知らせは、地域内で予定変更を共有するためのものです。
```

**「新しい予定：」の行が出ていることを目視してから、次へ進む。**

## 6. ショット⑥ ログ取込と作業履歴（6秒／構成案 64–70秒）

**目的.** 「まいた記録も、同じ案件に。あとから、まとめて取り出せます。」

1. 左メニューの **ドローン連携** をクリック
2. **「同梱ログを取込」** をクリック
3. 高度のグラフが出るまで**2秒ほど待つ**
4. 左メニューの **作業履歴** をクリック
5. 一覧をゆっくりスクロールし、**「履歴CSV」「履歴PDF」のボタンが見える**ところで止める

**映るはずのもの（確認済み）**

- 飛行時間 06:04–06:48、最大高度 3.4m、**高度のグラフ12本**（超過分が橙で表示）
- 作業履歴：記録件数5件、資材・面積・カバー率、CSV／PDF出力ボタン

> 延期を記録したあとに撮ると件数が変わる場合がある。
> 気になるなら**ショット⑥を先に撮り、そのあとで⑤（延期）を撮る**。
> 順番が入れ替わっても編集で並べ替えられる。

## 7. 撮り終えたら

- [ ] 6ショットすべてに「今日」の日付が入っているか（前回の日付が残っていないか）
- [ ] ブックマークバー・拡張機能・個人情報が映り込んでいないか
- [ ] ショット②で「文面コピー」を押す瞬間が入っているか
- [ ] ショット⑤で「**新しい予定：**」の行が映っているか
- [ ] マウスの動きが速すぎないか（追える速さか）

すべて確認できたら、**ここでKling AI Standard を契約する**
（`docs/動画キーフレーム指示.md` §6）。
