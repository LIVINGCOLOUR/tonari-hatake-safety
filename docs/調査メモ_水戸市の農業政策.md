**PDFからのテキスト抽出について。** 自治体のPDFは3種類ある。
(1) テキスト埋め込み＋Identity-H（2バイト）、(2) 1バイト文字列＋間接Font参照、

## 4. オーガニックビレッジ

### 水戸市は未宣言

市の公式ページに明記。**「オーガニックビレッジ宣言に向けた準備を進めているところです」**
3か年計画でも「宣言を行い」と将来形。
→ [有機農業で新規就農を目指しませんか（水戸市）](https://www.city.mito.lg.jp/site/iju/126541.html)

**JA水戸 有機農業研究会**が令和6年1月設立。地域おこし協力隊の受け入れ先。
協力隊の条件は月額206,500円〜、住宅補助7万円上限、軽トラと燃料費支給。

市が実際に行っている有機関連事業（[農産振興課](https://www.city.mito.lg.jp/soshiki/62/)）:
有機農業栽培技術講習会、有機農業の先進事例視察研修会、地域おこし協力隊募集。**担い手づくりのみ。**

### 制度の流れ

有機農業実施計画の**認定**によってオーガニックビレッジ宣言を行う。
支援事業を使う場合は「計画を検討 → 試行的に取組 → 宣言」の順。
→ [オーガニックビレッジ（農林水産省）](https://www.maff.go.jp/j/seisan/kankyo/yuuki/organic_village.html)

### 独自認証について

**県内に市町村独自の認証制度は見当たらない。** 認証は県、給食は市町村という役割分担がある。

- **茨城県特別栽培農産物認証制度** — 慣行比で節減対象農薬の使用回数50%以下・化学肥料窒素50%以下、約70品目。**栽培開始前に申請**（1〜6月開始なら前年11月、7〜12月開始なら同年5月）
- **いばらきみどり認定** — みどりの食料システム法に基づく。**エコファーマー認定は廃止され移行**

→ [特別栽培農産物（茨城県）](https://www.pref.ibaraki.jp/nourinsuisan/nougi/tokusai/contents04.html)
／ [いばらきみどり認定](https://www.pref.ibaraki.jp/nourinsuisan/ounourin/shinko/nogyo/ibarakimidorinintei.html)

**「無農薬」「減農薬」「無化学肥料」「減化学肥料」は表示禁止**（平成19年4月出荷分から）。
理由は消費者が「一切の残留農薬を含まない」と受け取り優良誤認を招くため。
代替は「節減対象農薬: 栽培期間中不使用」。
→ [特別栽培農産物に係る表示ガイドライン（農林水産省）](https://www.maff.go.jp/j/jas/jas_kikaku/tokusai_a.html)

**自治体独自認証には2つの型がある。**
Type A（認証制度型）= いばらきエコ等。国のガイドラインに上乗せ／緩和した基準＋独自マーク。
Type B（条例・出口型）= 木更津市「オーガニックなまちづくり条例」、今治市「食と農のまちづくり条例」、
いすみ市（2017年10月に学校給食を全量有機米に、後に給食費無償化）。
**成功しているのは明確にType B。認証は証明の仕組みであって、売れる仕組みではない。**

### 内原地区の記載（確認済み）

**10年後の目標: 計84経営体・418.57ha**

> **（4）多様な経営体の確保・育成の取組**
> 原則として地域内での担い手確保を推進するが、担い手の不足する集落等では、地域の機運に応じ、
> 中間管理事業を通じた地域外からの参入や、**狭小農地を活用した多様な就農**、
> 後継者のいない担い手の**第三者継承**等を促進する。また、国支援を活用した新規就農者の育成に
> おいては、JA、県、**市内農業専修学校等と連携**し、相談から就農、認定農業者への移行までを
> 切れ目なく支援していく。

選択された任意記載事項:
- ① 鳥獣被害防止対策（中妻・下中妻）
- ② **有機農業に取り組む担い手や、今後取組意向のある担い手を中心に、有機農業を推進するエリアの形成を検討する**
- ⑤ 果樹（ぶどう）での新規就農者の経営拡大
- ⑦ 多面的機能活動組織の拡大、**学校・地域コミュニティと連携した農業体験**
- ⑧ 施設園芸の担い手・新規就農者の経営拡大、次世代への継承
- ⑨ 集落営農組織による飼料用稲（WCS用稲）の生産等、耕畜連携

**「狭小農地を活用した多様な就農」が、3か年計画の「半農半X・小規模農地の活用」の実体。**
**「市内農業専修学校」は日本農業実践学園（内原町）。**

## 7. 小麦と食料自給率

### 「アメリカから一定量輸入する義務」は存在しない

- **ミニマム・アクセスは輸入義務ではない。**「年ごとの輸入量を義務づけているものではなく、
  最低限のアクセス機会（低い関税での輸入枠設定）の提供を行うことが義務づけられているもの」。
  **しかもこれは米の制度であって小麦の制度ではない**
- 小麦は主要食糧法に基づく国家貿易。政府が約9割を一括購入しマークアップを上乗せして売渡。
  年間約522万トン、米国・カナダ・豪州でほぼ100%
- 日米貿易協定は「小麦について**米国枠を設定**し、SBS方式による輸入・販売を行う」。
  WTO枠内の米国産小麦の最低マークアップ上限は15.3円/kg。**枠の設定であって義務ではない**
- **自治体まで義務が連鎖する法令・通知は存在しない。** 献立と食材調達は設置者（市町村）が決める

### 数字

| | 国内生産 | 輸入 | 自給率 |
| --- | --- | --- | --- |
| 1961年 | 178万トン | — | — |
| **1973年（底）** | **20万トン** | **531.9万トン** | **4%** |
| 2020年 | **95万トン** | 約500万トン | **15%** |

**アメリカからの輸入は減っている。** 2011年 324万トン（58%）→ 2024年 約200万トン（40.5%）。
カナダが23%→38.5%へ増加。

**一人当たり年間消費量**

| | 1965年 | 2020年 | 差 |
| --- | --- | --- | --- |
| 小麦 | 29.0kg | **31.7kg** | **+2.7kg** |
| 米 | 117.4kg | **50.7kg** | **−66.7kg** |

**「米が小麦に置き換わった」は誤り。** 米の減少分は肉・油脂・乳製品等に向かった。
小麦粉生産量は**1994年500万トンをピークに2023年463万トン**へ減少。

**店舗数（消費量の代理指標にはならない）:** そば・うどん店は2021年24,982店で10年で約25%減、
パン屋は約1万1千店で微減、ラーメンは上位50社が2010年度5,043店→2024年度6,200店（+23%）。
市場規模は増えているが単価上昇を含む。

### 実質的な縛りは財源構造

輸入小麦のマークアップが**国内産麦の生産振興（経営所得安定対策＝ゲタ対策）の財源**。
2023年度予算1,984億円。小麦の交付単価は1トンあたり約10万円。
**輸入が減ると国産支援の財源が細る。** 外国からの強制ではなく、日本自身が作った依存構造。

**価格:** 輸入小麦の政府売渡価格は令和7年4月期で**1トン63,570円**（5銘柄加重平均）。

## 8. 有機と水系

### 「下流だから有機ができない」は誤り

分かれ目は**用排兼用水路か用排分離か**。

- 有機JASは水田について**用排水図の提出**を求め、**非有機の水田の排水が対象ほ場に流入しないこと**が要件
- **用排兼用**（用水と排水を一本で兼ねる。圃場整備が未了の地域に多い）なら
  **浄化水田などの混入防止措置**が必要
- 河川・専用の用水路・井戸・水道・雨水からの取水なら措置は不要とされる
- 最終的には認証機関がほ場ごとに個別判断

**未確認。** 上記は検索結果からの整理で、[農水省Q&A](https://www.maff.go.jp/j/jas/jas_kikaku/pdf/qa_nousan_kakou.pdf)の
原文には当たれていない（PDFが機械的に読めない）。**山田農園さんに聞けば一発で分かる。**

**有機は点では広がらず、水系単位でしか広がらない。**
オーガニックビレッジが「地域ぐるみ」の制度設計なのは、おそらくこの構造による。

### 除草剤の水系への流出

- 水田除草剤には「**散布後7日間は落水・かけ流しをしない**」指導がある。
  **指導が存在すること自体が、流出が現実の問題である証拠**
- 流出要因として名指しされているのは**畦漏水**と**給水時のかけ流し等、給排水管理の不徹底**
- 新潟県の河川調査で**83物質のうち41物質が検出**され、用途別では**除草剤が殺虫剤・殺菌剤より
  検出頻度が高い**。検出時期は田植え後と降雨後に集中
- 環境省が「水質汚濁に係る農薬登録基準」を設け河川モニタリングを継続

**流入経路は4つ。** ① 田越し灌漑（上の田から下の田へ田そのものを通して流れる）
② 用水の反復利用 ③ 畦畔からの漏水 ④ 降雨による流出

**飛散との違い:** 越境が正常運転／特定がほぼ不可能（上流の全員が候補）／時間差がある。
**絞り込みの材料は「いつ・どこで・何を撒いたか」しかない。**

**畦畔・農道への散布は、7日間の落水禁止という管理体系の外側にある。**
湛水していないので止水管理の概念が成立せず、雨が降れば直接水路へ流れる。
同等の流出防止の枠組みは、調べた範囲では見つからなかった。

## 9. 衛星から分かること・分からないこと

### 農薬散布そのものは検知不能

理由3つ。量が少なすぎる（10aあたり数十〜数百グラム、無色、数日で分解・吸着）／
作業が速すぎる（数時間。Sentinel-2の再訪は5日周期）／解像度が足りない。

**殺虫剤・殺菌剤は植生を変えないため原理的に見えない。**
除草剤は効果（枯死）が見える可能性があるが、選択性なら作物のNDVIに埋もれ、
**畦畔は幅1〜2mで10m解像度に収まらない。**

### 水管理は高精度で見える

- 農研機構がSentinel-2で**水田の取水開始時期を把握する手法**を公開。**精度97%**
- 雲で光学が使えない日は**Sentinel-1のSAR**（雲を透過）。圃場区画データと組み合わせた
  湛水判別精度は**VV偏波79.1%／VH偏波75.8%**
- 代かき時期の広域把握もプレスリリース済み

**ただし湛水は水系のほぼ全員が同時に成立するため、誰が撒いたかの絞り込みにはならない。**
散布者が自分で記録していた場合に、記録と矛盾しないことの弱い裏付けにはなる。

**Copernicus Data Space Ecosystem の無料枠**

| Sentinel Hub API | 月間10,000 Processing Unit（毎分300PU） |
| APIリクエスト数 | 月50,000回 |

| データ転送量 | 12TB／30日（超過後1MB/sに減速） |

NDVIタイル1枚（256×256px）が約1〜3PU。**100圃場×5日周期で月6回なら600PU＝無料枠の6%。**
商用利用を明示的に禁じる記載は見当たらないが、規約の直接確認が必要（未確認）。

## 11. 「基準はあるが実施率を誰も知らない」構造

農業ではこれが例外ではなく標準。理由は3つ。
現場が分散していて監督が物理的に不可能（経営体約80万・圃場は数百万か所）／
法が想定する「事業者」がいない（家族経営・一人作業で雇用関係がない）／
天候に左右され標準化できないため基準が「〜に努める」の形にしかならない。

| 領域 | 基準の強さ | 実施率 |
| --- | --- | --- |
| ドローン散布の事前周知 | 局長通知のガイドライン。罰則なし | **不明** |
| 住宅地等における農薬使用の通知 | 平成25年の通知。罰則なし | **不明** |
| 農薬の使用記録 | 省令上の**努力義務** | **不明** |
| トラクタの安全装備 | ほぼ努力目標（上記） | **不明** |
| 農業用廃プラ・廃農薬 | **罰則あり**（5年以下の懲役／1,000万円以下の罰金）。ただし「やむを得ない野外焼却」の例外 | **不明** |
| 労働時間・休憩・休日 | **労基法41条で農業は適用除外** | ルール自体がない |
