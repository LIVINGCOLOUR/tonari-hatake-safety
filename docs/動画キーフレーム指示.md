**制作環境（2026-08-10 決定 ／ 動画生成を採用する形へ改訂）**

| 工程 | 使うもの | 備考 |
| --- | --- | --- |

### 動画生成を使う理由（2026-08-10 門田さん判断）

**静止画をゆっくり動かすだけではスライドショーに見え、製品まで安く見える。**
ヒアリングで見せる道具である以上、それは避ける。

### 無料で済ませられない理由

調べた範囲では、**完全無料かつ商用利用可の動画生成AIは事実上存在しない。**

| ツール | 無料枠 | 商用利用 |
| --- | --- | --- |
| Pika | あり | 不可（Pro 月$35から） |
| Kling AI | あり | 不可（Standard 月$6.99から可・透かし除去） |
| Vidu | あり（i2vを試せる） | 有料プランから（月$8〜） |
| Sora | ― | **2026年4月26日にサービス終了** |

**Kling AI Standard を1ヶ月だけ契約し、作り切って解約する。約1,000円。**
最安であり、一貫性とモーションの総合力が高く、商用利用の解放と透かし除去が
同じプランに含まれる。手描き調の再現に不満が出た場合は、アニメ調の塗り・線画の
再現で評判のVidu（月$8〜）へ切り替える。

### CapCut無料版で守ること

- 自分で用意した素材（生成画像・生成動画・画面録画）だけを使う
- **内蔵の音楽・テンプレート・エフェクトを使わない**（多くが商用利用不可）
- テンプレートを使わなければウォーターマークは入らない

## 0-2. 動かすカットと、止めるカット

**全カットを動かさない。** 「止まる」ことに意味を持たせた2カットがあり、
そこを動かすと意味が消える。動と静のコントラストがあるから動きが生きる。

| カット | 扱い | 動きの難易度 | 理由 |
| --- | --- | --- | --- |
| 1 夜明けの水田 | **動かす** | 低 | 水面のさざ波、霧の流れ。人物がおらず破綻しにくい |
| 2 軽トラとドローン | 動かす | 中 | 人物が動くため崩れやすい。破綻したらズームに落とす |
| 3 薬液を注ぐ | 動かす | 高 | 手指が破綻しやすい。無理なら静止＋ゆっくり寄り |
| 4 手が止まる | **止める** | ― | 「まく前に、やることがある」の一拍。ここで音も止める |
| 5 農地の俯瞰 | **動かす** | 低 | カメラをゆっくり前進させるだけ。効果が大きい |
| 6 夜の机 | 動かす | 中 | 指が地図をなぞる動き |
| 7 指が止まる | **止める** | ― | 「誰が対象かを知ることだ」の直前。一拍の無音 |
| 8 スマホを見る | **動かす** | 低 | 画面の光が強まるだけ。実画面への転換に使う |

**進め方.** 難易度「低」の1・5・8から作る。ここが決まれば動画としての体裁は整う。
中〜高（2・3・6）は生成してみて、崩れたらCapCutのパン・ズームに落とす。
**4・7は最初から生成しない。**

## 1. 絵柄の方針

**基準は「柔らかい手描きのエディトリアルイラスト」。** 自治体やJAの広報物に
よくある系統で、「親しみやすい公共の資料」として読まれる。

- 水彩と色鉛筆の質感、淡い配色、細く柔らかい線
- 余白を広く取る。要素を詰め込まない
- **マスコットキャラクターを主役にしない。** かわいさに寄せると
  「消費者向けアプリ」に見え、後半の業務ツール画面との距離が開く
- 人物は描いてよい（写実版と違い、実在の人物に見える問題が起きない）。
  ただし**特定の誰かに見えない、一般的な農家の姿**にする

### 登場人物（全カット共通）

> **農家。40〜60代。作業着（長袖の作業シャツかジャンパー）、キャップ、
> 長靴。穏やかで真面目な表情。特定の誰かに似せない。**

同じ人物を8カットで使うため、**1枚目を作ったら、以降は同じチャットの中で
「前の画像と同じ絵柄・同じ人物で」と指示して続ける。** これが一貫性を保つ最も確実な方法。

## 2. 基準画（最初に1枚。ここで全部が決まる）

**基準画は「カット4の構図」で作る。** 風景だけの絵ではなく、農家が立っている場面に
することで、**絵柄・人物・小道具・配色を1枚で同時に固定できる。**
以降の7カットは、この画を基準に同じチャットの中で続ける。

ChatGPT（GPT Image 2.0）に、次をそのまま貼る。

```
柔らかい手描き風のイラストを1枚描いてください。

【絵柄】
水彩と色鉛筆のような質感。淡くやさしい配色。細く柔らかな線。
落ち着いた大人向けの雰囲気にしてください。
幼い印象、キャラクターグッズ風、アニメ風にはしないでください。
日本の自治体や農協の広報冊子に使われるような、親しみやすく品のある挿絵。

【場面】
夜明けの日本の水田。田植え後まもない時期で、浅い水面に淡い空の色が映っている。
畦（あぜ）が水田を区切り、遠くに里山の稜線と木立が見える。
水田のふちに、農家がひとり立っている。
足もとには農薬散布用のドローン（液剤タンクと散布ノズルが付いた機体）が
地面に置いてある。
農家は作業の手を止めて、田んぼの向こうを静かに見ている。

【人物】
40〜60代の農家。長袖の作業シャツかジャンパー、キャップ、長靴。
穏やかで真面目な表情。特定の誰かに似せない、一般的な農家の姿。

【色】
夜明けの淡い青、水面の銀、土の茶、稲の緑を基調に。
赤は使わないか、ごく小さく。

【描かないでください】
文字、ロゴ、看板、ナンバープレート。
防護服、ガスマスク。薬剤の霧や煙。
枯れた作物、傷んだ畑。
怖い雰囲気、暗く重い色調、強い赤。
ドローンは飛ばさず、地面に置いた状態で描いてください。

横長16:9。
```

### 基準画で確認すること

この1枚が全カットの基準になるため、**納得いくまで作り直す。** 見る点は次の6つ。

1. **業務ツールと繋がるトーンか。** 後半はアプリの実画面（濃い緑のサイドバー、表、地図）。
   絵が幼すぎると別の製品に見える
2. **農家が一般的な姿か。** 特定の誰かに似ていないか
3. **ドローンにタンクとノズルがあるか。** 空撮用の小型機や軍事的な機体になっていないか
4. **文字が入っていないか**
5. **赤や濃い色が目立たないか**
6. **日本の農村に見えるか。** 畦、里山、水田の見え方が不自然でないか

### 直したいときの言い方

- 幼く見える → 「**もう少し落ち着いた大人向けの絵柄にしてください。線を細く、
  色を淡くしてください**」
- 硬い・冷たい → 「**もう少し手描きのやわらかさを出してください**」
- ドローンが違う → 「**ドローンは農薬散布用の機体です。下に液剤タンクと
  散布ノズルが付いています。もう少し大きく、しっかり描いてください**」
- 色が濃い → 「**全体をもっと淡く、水彩のにじみのある感じにしてください**」
- 人物が若い／子供っぽい → 「**40〜60代の落ち着いた農家にしてください**」

### 基準画が決まったあと

**同じチャットの中で**、カット1・2・3・5・6・7・8を順に作る。
各プロンプトの冒頭に必ず次を置く。

```
前の画像と同じ絵柄・同じ人物・同じ配色で、続けて描いてください。
```

チャットを新しく開くと絵柄がリセットされるため、**8枚すべてを1つのチャットで作る。**

## 3. 全カット共通の禁止事項

各プロンプトの末尾に、必要に応じて足す。

```
次のものは描かないでください。
文字、ロゴ、看板、ナンバープレート。
防護服、ガスマスク。
散布された薬剤の霧や煙。特に人家やカメラへ向かうもの。
枯れた作物、傷んだ畑。
言い争う人、怒っている人、指をさす人。
地図上の標的マーカー、照準、枠線、走査線、赤いグリッド。
軍事用ドローン、玩具のドローン。
低空で人に向かうドローン、傾いたドローン、墜落。
公印、承認スタンプ。
怖い雰囲気、暗く重い色調、強い赤。
```

**イラストにしたことで、写実版にあった危険の多くは自然に消える。**
それでも「農薬散布」という語からAIが警告色や霧を出すことがあるため、上記は残す。

## 4. カット別の指示

### カット1 ── 夜明け前の水田（0–6秒）

**意図.** 散布という仕事を、静かで美しい朝の営みとして始める。
1カット目で「散布者は敵ではない」を示す。

```
夜明け前の日本の水田を、横長の風景で描いてください。
田植え後まもない時期で、浅い水面に淡い空の色が映っています。
薄い朝もやが低く流れ、畦（あぜ）が水田を区切っています。
遠くに里山の稜線と木立、細い農道に白い軽トラックが小さく見えます。
風がなく、とても静かな朝。人は描かないでください。
```

**動き（Kling i2v・難易度 低）.** 生成時の指示:
> 水面がごくわずかに揺れ、朝もやが左から右へゆっくり流れる。
> カメラはゆっくり前へ進む。人や物は動かさない。静かなまま。

---

### カット2 ── 軽トラとドローン（6–9秒）

**意図.** 道具と仕事を示す。実在する現場に見せる。

```
前の画像と同じ絵柄で。
早朝、水田のわきの細い農道に白い軽トラックが停まっています。
荷台に、農薬散布用の大きなドローン（液剤タンクと散布ノズルが付いた
マルチコプター）が置かれています。
作業着とキャップの農家（40〜60代）が、荷台のそばで準備をしています。
朝の柔らかな斜光。落ち着いた雰囲気。
```

**動き（Kling i2v・難易度 中）.** 生成時の指示:
> 農家が荷台のドローンに手を伸ばし、ゆっくり点検する。
> カメラは静かに横へ流れる。ドローンは飛ばさない。
>
> **崩れたら諦める。** 人物の動きが破綻したらCapCutの横パンに落とす。

> **注意.** 「農薬散布用の、液剤タンクと散布ノズルが付いた」を必ず書く。
> 省くと空撮用の小型ドローンや、軍事的な機体が出る。

---

### カット3 ── 薬液を積む（9–11秒）

**意図.** 手元の丁寧さ。仕事への敬意。

```
前の画像と同じ絵柄・同じ農家で。
農家が、軽トラックの荷台に置いた散布用ドローンのタンクへ、
容器から液体を静かに注いでいます。
手元と上半身が中心の構図。丁寧で慎重な所作。
朝の光。落ち着いた色。
```

**動き（Kling i2v・難易度 高）.** 生成時の指示:
> 容器から液体がゆっくりタンクへ注がれる。手はほとんど動かさない。
> カメラはわずかに寄る。
>
> **手指が破綻しやすい。** 崩れたら静止画＋ゆっくりした寄りに落とす。
> このカットは動かなくても成立する。

---

### カット4 ── 手が止まる（11–15秒）★入口

**意図.** 「まく前に、知らせる。」の一拍。**この動画の入口。**

> **このカットは §2 の基準画そのもの。** 改めて生成せず、基準画を使う。

**動き.** **静止（動画生成しない）。** ここで音も止める。
止まっていることに意味があるカット。動かすと「立ち止まった」意味が消える。

---

### カット5 ── 農地の俯瞰（15–23秒）★最重要

**意図.** 「知らせるべき相手が、この中にいる」の土台。
学校・巣箱・有機ほ場のアイコンは**編集で載せる**。

```
前の画像と同じ絵柄で。
日本の農村を、斜め上から見おろした広い風景として描いてください。
水田と小さな畑が、畦と細い農道で区切られて continuous に広がっています。
点在する農家の建物、小さなビニールハウスが1棟、
はしに小学校の校舎と数軒の家、その先に木立と低い山。
昼間の穏やかな光。
地図の記号、印、枠、色分けは一切入れないでください。
きれいな風景画のままにしてください。
```

**動き（Kling i2v・難易度 低）.** 生成時の指示:
> カメラがゆっくり前へ進み、農地の上を静かに移動する。
> 風で木立がわずかに揺れる。**追いかける動き、急な動き、回り込みはしない。**
>
> **効果が大きく、破綻しにくい。優先して作る。**
> ただし速く動かすと監視・偵察の映像に見える。あくまで穏やかに。

> **★ここが監視の絵になるかどうかの分かれ目。**
> 生成時にマーカー・枠・色分けを一切入れさせない。
> アイコンは編集時に、**素朴な地図記号として静かに灯す**。
> 赤い標的、走査線、追尾枠は絶対に使わない。
> **真上からの構図にしない。** 斜め上からの俯瞰にする。真上は監視の絵になる。

---

### カット6 ── 夜の机（23–28秒）

**意図.** 「誰が対象かを知る」ことの難しさを、静かな手元で描く。責めない。

```
前の画像と同じ絵柄・同じ農家で。
夜、家の中の机に向かっている農家。
机の上には、農地を写した航空写真をプリントした紙が広げてあり、
農家は指でその上をたどっています。
無地の付箋が数枚と、ペン、老眼鏡。
机の上の小さな明かりだけが灯り、窓の外は暗い。
静かで、少し考え込んでいる様子。
付箋や紙に文字は書かないでください。
```

**動き（Kling i2v・難易度 中）.** 生成時の指示:
> 指が地図の上をゆっくりたどる。ランプの光がわずかに揺れる。
> カメラは静かに寄る。
>
> 崩れたらCapCutのゆっくりした寄りに落とす。

> **注意.** 付箋は**無地**にする。文字を書かせると意味不明な文字列が出る。

---

### カット7 ── 手が止まる（28–30秒）

**意図.** 「難しいのは、誰が対象かを知ることだ。」の直前の一拍。

```
前の画像と同じ絵柄・同じ農家で。
夜の机。広げた航空写真の上に置いた手が、動きを止めています。
農家は少し眉を寄せて、紙の一点を見ています。
明かりは机の上だけ。まわりは暗い。
静止した、静かな場面。
```

**動き.** **静止（動画生成しない）。ここで一拍の無音**（`docs/紹介動画構成案.md` §7）。
直前のカット6が動いているぶん、ここで止まると効く。

---

### カット8 ── スマホを見る（33–34秒）★実画面への橋

**意図.** **イラストからアプリ実画面への転換をつなぐ。**
これがないと、水彩から業務ダッシュボードへ唐突に切り替わる。

```
前の画像と同じ絵柄・同じ農家で。
農家がスマートフォンを手に持って見ています。
画面の側からやわらかい光が顔に当たっています。
スマートフォンの画面の中身は描かず、白く光らせてください。
明るく、前向きな表情。
背景は簡単に、朝の水田。
```

**動き（Kling i2v・難易度 低）.** 生成時の指示:
> スマートフォンの画面の光がゆっくり強くなる。
> カメラが静かに画面へ寄っていく。人物はほとんど動かさない。

編集では、この白い光が画面いっぱいになったところで**実画面録画へディゾルブ**する。

### 動画生成で崩れたときの判断

**粘らない。** i2vは同じ画像でも結果が毎回変わるため、3〜4回試して崩れるなら
その構図は動かない。静止画に戻して次へ進む。
**8カット中5つ動いていれば、スライドショーには見えない。**

監視に見えるリスクがさらに下がる。

### cut19 ── 自宅の机でスマホを手に取る（33–34秒の転換用）

`cut06`・`cut07`（夜の机）と同じ場所・同じ流れにすることで、
「地図を見ていた人が、そのままスマホで知らせる」と自然につながる。

```
前の画像と同じ絵柄・同じ人物で、続けて描いてください。

夜の家の中の机。前に描いたのと同じ机です。
広げた航空写真の紙が机の上にあり、農家がスマートフォンを手に取って
画面を見ています。
机の上の明かりだけが灯り、窓の外は暗い。
無地の付箋とペンが机の端にあります。

スマートフォンの画面の中身は描かず、白く光らせてください。
落ち着いた、少し前向きな表情。

【描かないでください】
文字、ロゴ。付箋や紙の文字。アプリの画面の中身。強い赤。怖い雰囲気。

横長16:9。
```

**動き（Kling i2v・難易度 低）.** 画面の光がゆっくり強くなる。カメラが静かに寄る。
編集では、白い光が画面いっぱいになったところで**実画面録画へディゾルブ**する。

### cut20 ── 自宅の机でスマホを操作する手元（42–50秒の投稿用）

実写のショット③を撮らない場合の代替。手元だけで、顔を入れない。

```
前の画像と同じ絵柄で、続けて描いてください。

夜の机の上で、スマートフォンを両手で持って操作している手元を大きく描いてください。
机には広げた航空写真の紙と、無地の付箋、ペンがあります。
机の明かりが手元を照らしています。
顔は入れないでください。

スマートフォンの画面の中身は描かず、白く光らせてください。

【描かないでください】
文字、ロゴ。付箋や紙の文字。アプリの画面の中身。顔。強い赤。

横長16:9。
```

**動き（Kling i2v・難易度 中）.** 指がゆっくり画面をなぞる。手指が崩れたら静止画にする。

> **生成時の注意.** 新しいチャットで作る場合は、`cut06-night-desk-v1.png` を
> 添付して「この絵柄・この人物・この机で続けて描いてください」と伝える。

## 6-3. 追加生成バッチ

編集時の選択肢を増やすための追加素材は `docs/動画キーフレーム生成バッチ.md` に
プロンプトをまとめてある（締めのカット、悪天候、学校・養蜂・有機ほ場、

バッチ側の【描かないでください】を必ず含めて実行する。
