# 紹介動画 キーフレーム生成指示（手描きイラスト版）

作成: 2026-08-10 ／ 改訂: 2026-08-10（写実からイラストへ全面変更）
対応: `docs/紹介動画構成案.md` 第5-1節
状態: 未生成

**制作環境（2026-08-10 決定）**

| 工程 | 使うもの | 備考 |
| --- | --- | --- |
| 画像生成 | **ChatGPT（GPT Image 2.0）** | Plusで3時間ごと最大50枚。商用利用は規約上可 |
| 動画化 | **使わない（CapCutのズーム・パンで代用）** | 下記「なぜPikaを使わないか」参照 |
| 編集 | **CapCut 無料版** | 内蔵の音楽・テンプレート・エフェクトは使わない |
| 音楽 | 商用利用可のフリー音源を別途 | DOVA-SYNDROME、甘茶の音楽工房 等 |

### なぜPikaを使わないか

1. **無料プラン（Basic）は商用利用が禁止。** 許可されるのはProプラン（月$35）以上。
   対面で数人に見せる場合でも、事業の紹介である以上は商用利用にあたる
2. 無料版はウォーターマークが入る
3. **そもそも不要。** 構成案は「動きは最小限」と決めており、CapCutのズーム・パンで足りる
4. **イラストにAI動画をかけると品質が落ちる。** 顔や手が歪み、絵柄の一貫性が崩れる。
   静止画をゆっくり動かすほうがこの絵柄では確実にきれい

### CapCut無料版で守ること

- 自分で用意した素材（生成画像・画面録画）だけを使う
- **内蔵の音楽・テンプレート・エフェクトを使わない**（多くが商用利用不可）
- テンプレートを使わなければウォーターマークは入らない

## 1. 絵柄の方針

**基準は「柔らかい手描きのエディトリアルイラスト」。** 自治体やJAの広報物に
よくある系統で、「親しみやすい公共の資料」として読まれる。

- 水彩と色鉛筆の質感、淡い配色、細く柔らかい線
- 余白を広く取る。要素を詰め込まない
- **マスコットキャラクターを主役にしない。** かわいさに寄せると
  「消費者向けアプリ」に見え、後半の業務ツール画面との距離が開く
- 人物は描いてよい（写実版と違い、実在の人物に見える問題が起きない）。
  ただし**特定の誰かに見えない、一般的な農家の姿**にする

### 登場人物（全カット共通）

> **農家。40〜60代。作業着（長袖の作業シャツかジャンパー）、キャップ、
> 長靴。穏やかで真面目な表情。特定の誰かに似せない。**

同じ人物を8カットで使うため、**1枚目を作ったら、以降は同じチャットの中で
「前の画像と同じ絵柄・同じ人物で」と指示して続ける。** これが一貫性を保つ最も確実な方法。

---

## 2. スタイル指定（最初に1回、基準画を作る）

まず次を投げて**基準画**を作り、絵柄を確定させる。以降のカットはこの画を基準に続ける。

```
柔らかい手描き風のイラストで描いてください。
水彩と色鉛筆のような質感、淡くやさしい配色、細く柔らかな線。
日本の農村（茨城県の里山と水田）の風景。
落ち着いた大人向けの雰囲気で、幼い印象にはしないでください。
色は、夜明けの淡い青、水面の銀、土の茶、稲の緑を基調に。
赤は使わないか、ごく小さく。
文字は一切入れないでください。
横長16:9。
```

---

## 3. 全カット共通の禁止事項

各プロンプトの末尾に、必要に応じて足す。

```
次のものは描かないでください。
文字、ロゴ、看板、ナンバープレート。
防護服、ガスマスク。
散布された薬剤の霧や煙。特に人家やカメラへ向かうもの。
枯れた作物、傷んだ畑。
言い争う人、怒っている人、指をさす人。
地図上の標的マーカー、照準、枠線、走査線、赤いグリッド。
軍事用ドローン、玩具のドローン。
低空で人に向かうドローン、傾いたドローン、墜落。
公印、承認スタンプ。
怖い雰囲気、暗く重い色調、強い赤。
```

**イラストにしたことで、写実版にあった危険の多くは自然に消える。**
それでも「農薬散布」という語からAIが警告色や霧を出すことがあるため、上記は残す。

## 4. カット別の指示

### カット1 ── 夜明け前の水田（0–6秒）

**意図.** 散布という仕事を、静かで美しい朝の営みとして始める。
1カット目で「散布者は敵ではない」を示す。

```
夜明け前の日本の水田を、横長の風景で描いてください。
田植え後まもない時期で、浅い水面に淡い空の色が映っています。
薄い朝もやが低く流れ、畦（あぜ）が水田を区切っています。
遠くに里山の稜線と木立、細い農道に白い軽トラックが小さく見えます。
風がなく、とても静かな朝。人は描かないでください。
```

**動き（CapCut）.** ごく緩やかに寄る。5〜6秒かけて1.0→1.08倍程度。

---

### カット2 ── 軽トラとドローン（6–9秒）

**意図.** 道具と仕事を示す。実在する現場に見せる。

```
前の画像と同じ絵柄で。
早朝、水田のわきの細い農道に白い軽トラックが停まっています。
荷台に、農薬散布用の大きなドローン（液剤タンクと散布ノズルが付いた
マルチコプター）が置かれています。
作業着とキャップの農家（40〜60代）が、荷台のそばで準備をしています。
朝の柔らかな斜光。落ち着いた雰囲気。
```

**動き.** ゆっくり横へ流す、または緩やかに寄る。

> **注意.** 「農薬散布用の、液剤タンクと散布ノズルが付いた」を必ず書く。
> 省くと空撮用の小型ドローンや、軍事的な機体が出る。

---

### カット3 ── 薬液を積む（9–11秒）

**意図.** 手元の丁寧さ。仕事への敬意。

```
前の画像と同じ絵柄・同じ農家で。
農家が、軽トラックの荷台に置いた散布用ドローンのタンクへ、
容器から液体を静かに注いでいます。
手元と上半身が中心の構図。丁寧で慎重な所作。
朝の光。落ち着いた色。
```

**動き.** ほぼ静止。ごく緩やかに寄る。

---

### カット4 ── 手が止まる（11–15秒）★入口

**意図.** 「まく前に、知らせる。」の一拍。**この動画の入口。**

```
前の画像と同じ絵柄・同じ農家で。
水田のふちに立つ農家を、少し離れた位置から描いてください。
足もとに散布用ドローンが置かれています。
農家は作業の手を止めて、田んぼの向こうをじっと見ています。
穏やかで、少し考えているような表情。
まわりは静かな朝の風景。
```

**動き.** 静止。ここで音を止める。

---

### カット5 ── 農地の俯瞰（15–23秒）★最重要

**意図.** 「知らせるべき相手が、この中にいる」の土台。
学校・巣箱・有機ほ場のアイコンは**編集で載せる**。

```
前の画像と同じ絵柄で。
日本の農村を、斜め上から見おろした広い風景として描いてください。
水田と小さな畑が、畦と細い農道で区切られて continuous に広がっています。
点在する農家の建物、小さなビニールハウスが1棟、
はしに小学校の校舎と数軒の家、その先に木立と低い山。
昼間の穏やかな光。
地図の記号、印、枠、色分けは一切入れないでください。
きれいな風景画のままにしてください。
```

**動き.** ごく緩やかに寄る、または微かに横へ流す。

> **★ここが監視の絵になるかどうかの分かれ目。**
> 生成時にマーカー・枠・色分けを一切入れさせない。
> アイコンは編集時に、**素朴な地図記号として静かに灯す**。
> 赤い標的、走査線、追尾枠は絶対に使わない。
> **真上からの構図にしない。** 斜め上からの俯瞰にする。真上は監視の絵になる。

---

### カット6 ── 夜の机（23–28秒）

**意図.** 「誰が対象かを知る」ことの難しさを、静かな手元で描く。責めない。

```
前の画像と同じ絵柄・同じ農家で。
夜、家の中の机に向かっている農家。
机の上には、農地を写した航空写真をプリントした紙が広げてあり、
農家は指でその上をたどっています。
無地の付箋が数枚と、ペン、老眼鏡。
机の上の小さな明かりだけが灯り、窓の外は暗い。
静かで、少し考え込んでいる様子。
付箋や紙に文字は書かないでください。
```

**動き.** ゆっくり寄る。

> **注意.** 付箋は**無地**にする。文字を書かせると意味不明な文字列が出る。

---

### カット7 ── 手が止まる（28–30秒）

**意図.** 「難しいのは、誰が対象かを知ることだ。」の直前の一拍。

```
前の画像と同じ絵柄・同じ農家で。
夜の机。広げた航空写真の上に置いた手が、動きを止めています。
農家は少し眉を寄せて、紙の一点を見ています。
明かりは机の上だけ。まわりは暗い。
静止した、静かな場面。
```

**動き.** 静止。**ここで一拍の無音**（`docs/紹介動画構成案.md` §7）。

---

### カット8 ── スマホを見る（33–34秒）★実画面への橋

**意図.** **イラストからアプリ実画面への転換をつなぐ。**
これがないと、水彩から業務ダッシュボードへ唐突に切り替わる。

```
前の画像と同じ絵柄・同じ農家で。
農家がスマートフォンを手に持って見ています。
画面の側からやわらかい光が顔に当たっています。
スマートフォンの画面の中身は描かず、白く光らせてください。
明るく、前向きな表情。
背景は簡単に、朝の水田。
```

**動き.** スマホ画面の白い光に寄っていき、**そのまま実画面録画へディゾルブ**。

## 5. 検品リスト（1つでも該当したら採用しない）

- [ ] 文字・ロゴ・看板が描かれている（付箋の文字を含む）
- [ ] 8カットで絵柄や人物が変わっている
- [ ] 幼い印象・キャラクターグッズ風になっている
- [ ] 防護服・ガスマスクが描かれている
- [ ] 薬剤の霧・煙が描かれている
- [ ] 枯れた作物、傷んだ畑が描かれている
- [ ] 俯瞰図に枠・標的・走査線・グリッド・色分けがある
- [ ] 俯瞰が真上からになっている（斜め俯瞰でない）
- [ ] ドローンにタンクとノズルがない、軍事的、玩具に見える
- [ ] ドローンが傾いている、低空で人へ向かっている
- [ ] 赤が目立つ、色が濃い、怖い雰囲気になっている
- [ ] 日本の農村に見えない（畦、軽トラ、里山が不自然）
- [ ] 人物が特定の誰かに似ている

## 6. 作業の進め方

1. §2の基準画を作り、**絵柄を確定させる**（ここで納得いくまで粘る。以降が全部これに従う）
2. 同じチャットの中で、カット1〜8を順に「前の画像と同じ絵柄・同じ人物で」と続ける
3. 各カット5〜10枚生成して選ぶ。**3時間で50枚**の枠があるので、2回に分ければ1日で足りる
4. §5の検品リストで落とす
5. CapCutへ取り込み、各カットにゆっくりしたズーム・パンをかける
6. テロップ、俯瞰図のアイコン、実画面録画を重ねる
