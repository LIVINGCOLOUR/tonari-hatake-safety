## 1. 目的

**製品を売り込むためではなく、未検証の仮説を潰すために行う。**

現時点で最も重要な未検証事項は次のとおり（`BUSINESS_MODEL.md` §2・§9）。

| # | 仮説 | 状態 |
| --- | --- | --- |
| H1 | ガイドラインが求める事前の周知が実行されない主な理由は、意欲ではなく「対象を知る手段がない」ことである | **最重要・未検証** |
| H2 | 散布日程は数週間前に決まり、直前に確定・延期される | 未検証（時系列の前提） |
| H3 | 散布者は、周辺の有機・養蜂・収穫直前ほ場を把握できていない | 未検証（§3-0 二層構造の前提） |
| H4 | 延期・変更の再連絡は、現状ほとんど行われていない | 未検証（§3-1 二段階の後半の前提） |
| H5 | 機体所有は少数の受託事業者に集約されている | 全国統計からの推定。地域では未検証 |
| H6 | 受託事業者は「発注元に示せる記録」に価値を感じる | 未検証（主訴求の前提） |
| H7 | JA・受託法人は組織アカウントに年5〜10万円を払う | 未検証（収益の前提） |
| H8 | 保険請求では散布時の条件を問われる | 未検証（訴求の前提） |
| H9 | 人手・地上散布のほうが、周辺への影響は大きい | 未検証（2026-08-25 追加。射程の判断に必要） |
| H10 | 常時雇用の労働力が増えたことで、空き時間に、従来は行われなかった**圃場外**（畦畔・農道・法面）への除草剤散布が発生している | 未検証（2026-08-26 追加。現場の証言1件） |
| H11 | 一般住民は、自分でQRから登録してでも周囲の散布予定と直前の変更を知りたい | 未検証（2026-10-01 追加）。有機農家・学校など重点層の必要性は検証不要の前提（門田さん判断） |

**H1の前提。** 空中散布ガイドライン第2の2(1)(2)は、周辺に有機ほ場・養蜂・学校等がある場合の
事前の情報提供（日時・目的・使用農薬の種類・連絡先）と、天候等で日時が変わったときの再提供を
**求めている**（`RULES_AND_GUIDELINES.md` §2）。したがってH1は「通知したいか」という意向を
問う仮説ではない。**求められていることが実行されない理由**を問う仮説である。
この形は §2 原則1「意見でなく、行動を聞く」とも一致する。

**H9について。** 門田さんの観察では、ドローン散布者はDIPSの飛行計画通報や機体メーカーの
クラウドを既に使っておりITリテラシーがある一方、人手散布には高齢者が多く、
**本人がデジタルで記録を残すことはほぼ期待できない**（2026-08-25）。
本アプリで解けるのはドローン側であり、対象選定はこれで正しい。人手散布は
`RULES_AND_GUIDELINES.md` §5・§8のとおり射程には入っているが、**今は解かない**。

**H10について（2026-08-26、現場の証言1件）。** 「外国人労働者を安価で雇えるようになったが
持て余しており、手が空いた時間に、今までやっていなかった場所の除草剤散布をさせている」
という話を得た。`docs/現場メモ.md` 参照。

構造は**知識の不足ではなく、労働力の固定費化**である。以前は除草が自分や家族の労働で
機会費用が高く、やらなくてよい場所はやらなかった。常時雇用があると空き時間の限界費用が
ゼロに見えるため、必要のない作業が発生する。**国籍とも能力とも関係なく成立する構造で、
日本人を常時雇用しても同じことが起きる。**

なぜ効くか。対象が**圃場の外**（畦畔・農道・法面・水路脇）だからである。そこは
管理責任が曖昧で、記録の義務がなく（省令上の努力義務すら圃場の話）、空中散布ガイドラインの
対象外で、**そして有機ほ場や水路に最も近い**。`RULES_AND_GUIDELINES.md` §5・§8 が扱う
人手・地上散布の中でも、最も記録が残らない領域にあたる。

あわせて、雇って任せている以上**雇用主自身も誰がどこに撒いたかを把握していない可能性**がある。
これは §3-B 質問34（辞めた人の記録はどうなるか）と同型で、H6の傍証になりうる。

**語り方の制約（絶対）。** これを「外国人が余計な除草剤を撒いている」という形で述べない。
`AGENTS.md` の「被害原因を判定しない」に反するうえ、資料や会話に出た瞬間に
差別の文脈へ回収され、`BUSINESS_MODEL.md` §10 の語り分けが崩れる。述べるときは
**「人を雇えるようになったことで、これまで手が回らなかった場所の除草まで行われるようになった」**
という雇用構造の記述にとどめる。出所も明かさない（§5）。
また**畦畔の除草そのものを否定しない。** 高齢化で草刈りが回らないなら除草剤は合理的な選択で、
そこを否定すると「農薬反対の人」に戻る。問題は**必要以上に、記録なく、有機ほ場の隣で**
行われることである。

ただし「人手散布のほうが被害が大きい」は未検証である。件数の多さと記録の不在からは
あり得るが、一般に地上散布は散布高度が低いぶんドリフト自体は空中散布より小さいとされる。
**件数で大きいのか、1件あたりで大きいのか**を分けて聞く。§3-C（周辺農家）で確かめる。

**事前周知の実施率を示す公式統計は存在しない**（`RULES_AND_GUIDELINES.md` §2）。
したがってここで聞き取った内容が一次データになる。記録を残すこと。

## 2. 聞き方の三原則

### 原則1: 意見でなく、行動を聞く

将来の意向を尋ねると、人は相手を気づかって肯定的に答える。**過去の具体的な行動と
数字だけが判断材料になる。**

| 聞かない | 聞く |
| --- | --- |
| こういうアプリがあったら使いますか | 直近の散布では、どうされましたか |
| 事前通知は必要だと思いますか | 直近の散布で、どなたに伝えましたか |
| いくらなら払えますか | 今、その作業に何時間かけていますか |
| 記録は大事だと思いますか | 前に揉めたとき、何を見せましたか |

### 原則2: 責めない

**「連絡していますか」は詰問になる。** 相手は散布している当事者であり、
こちらは味方の立場で来ている（`BUSINESS_MODEL.md` §10）。
「できた／できなかった」の構造を聞く形にする。

- ×「事前の連絡はされていますか」
- ○「直近の散布では、どなたに伝えましたか」→「**伝えたくても連絡先が分からない、
  という相手はいらっしゃいますか**」

「違反」「守っていない」「本来は」という語を使わない。

### 原則3: 売り込まない

**デモは、相手から「見せて」と言われるまで開かない。** 開く前に一言断る。
SSメンバーの助言（いきなり売り込むと警戒される）をそのまま守る。

紙（`docs/散布者向け説明A4.html`）は最後に置いていく。最初に配らない。

## 3. 相手別の質問

### A. 散布者・ドローン受託事業者（最優先）

所要45〜60分。**A群→B群を必ず聞く。** C以降は時間と相手による。

#### A群 いつ・誰が決めるか（H2の検証）

1. 直近の散布はいつでしたか。作物と、だいたいの面積は。
2. **その日に撒くと決まったのは、いつの時点でしたか。**（数週間前／数日前／前日／当日朝）
3. 決めたのはどなたですか。（ご自身／委託元の農家／JA・防除組合の一斉指示）
4. この1シーズンで、天候で延期したことは何回ありましたか。
5. **延期したとき、どなたかに連絡しましたか。どうやって。**（H4の核心）

#### B群 誰に、どう伝えているか（H1・H3の検証）

6. 散布の前に、周りの方へ伝えることはありますか。直近ではどなたに伝えましたか。
7. どうやって伝えましたか。（電話／訪問／回覧／JA経由／LINE／看板／伝えていない）
8. それは何件くらいで、どのくらい時間がかかりましたか。
9. **伝えたいけれど連絡先が分からない、という相手はいらっしゃいますか。**
   （伝えない相手がいる場合）差し支えなければ、それはどういう相手が多いですか。
   → **§4の「理由の分類」に必要。責める調子にならないよう、相手が話し出したときだけ聞く**
10. **隣接するほ場が有機か、農薬を使っていないかは、どうやって分かりますか。**
11. 養蜂の巣箱がどこにあるかは、分かりますか。
12. 隣のほ場を今どなたが作っているか、変わったときはどうやって知りますか。

> 9〜12で「分からない」が出れば、地図で重点対象を出す機能の価値が確定する。
> 逆に全部把握できているなら、§3-0の二層構造の前提が崩れる。

#### C群 トラブルと記録（H6・H8の検証）

13. 飛散や苦情で話し合いになったことはありますか。（ご自身でも、周りで聞いた話でも）
14. **そのとき、いつ・どこで・どんな条件で撒いたかを示せる資料はありましたか。**
15. 賠償責任保険には入っていますか。年間どのくらいですか。
16. 保険を使ったこと、または請求を検討したことはありますか。**何を求められましたか。**
17. （受託の場合）委託元へ実施の報告は出しますか。**形式と、作成にかかる時間は。**
18. （受託の場合）発注元から記録の提出を求められたことはありますか。

#### D群 ガイドラインの実務（支援訴求の検証）

19. 散布計画書（県の協議会宛）は、どなたが出していますか。手間はどうですか。
20. 実績報告書はどうですか。
21. DIPSの飛行計画の通報は、毎回されていますか。
22. 散布前のチェックは、何かに記録していますか。

#### E群 今の道具（H5の検証）

23. 散布の記録は今どうつけていますか。（紙／Excel／アプリ／メーカーのクラウド）
24. 機体メーカーのログは見ますか。何のために。
25. この地域で、機体をご自身で持っている農家さんはどのくらいいますか。
    **多くは受託でしょうか。**
26. 使っている農業アプリはありますか。

#### F群 最後に

27. （ここで初めて）今こういうものを作っていて、少しお見せしてもいいですか。
28. 他にお話を伺える方をご紹介いただけますか。

29. 組合員から、散布についての相談や苦情は年に何件くらい来ますか。
30. そのとき、何を確認しますか。手元に資料はありますか。

### C. 周辺農家（有機・農薬不使用など）

**慎重に扱う。** 相手は被害を受けた側になり得る。製品の話より先に、事実を聞く。

36. 隣で散布があると分かるのは、いつ、どうやってですか。
37. 分からないまま撒かれていた、ということはありますか。
38. そのとき、何が困りましたか。（出荷、検査、収穫の判断など）
39. 事前に分かっていたら、何ができましたか。
40. 散布する方に、こちらの事情（有機である、収穫が近い等）は伝わっていると思いますか。
41. **困ったのは、ドローンによる散布と、人手・乗用機械による散布と、どちらが多いですか。**
    （H9の検証。件数が多いのか、1回あたりが大きいのかを分けて聞く）
42. 人手での散布の場合、事前に何か連絡はありますか。ドローンのときと違いはありますか。

43. **畦畔や農道の草は、いつ、誰が、どうやって処理していますか。**
44. **5年前と比べて、除草剤を撒く場所は変わりましたか。**
45. （相手が人手や雇用の話を持ち出したときだけ）**人を雇うようになって、
    作業のやり方は変わりましたか。**

> 41〜42はH9の検証。「人手のほうが多い」が繰り返し出るなら、射程の判断
> （`RULES_AND_GUIDELINES.md` §8をいつ実装するか）に影響する。
> ただし本アプリで解けるのはドローン側であり、ここで方針は変えない。
>
> **43〜45はH10の検証。国籍を一切持ち出さずに同じ実態へ届く形にしてある。**
> 45は相手が自分から雇用の話をしたときだけ聞く。こちらから振らない。
> 45を先に聞くと誘導になり、§2 原則1（意見でなく行動を聞く）から外れる。

## 4. 判断の基準 ―― 撤退ではなく、普及の経路を見極める

### 前提（2026-08-10 門田さん判断）

ドローンによる散布は普及の初期段階にあり、**ガイドラインに沿った事前の情報提供が
広く行われていない可能性が高い。**

**これは需要がないことの証拠ではなく、まだ満たされていない要件があることの証拠。**
空中散布ガイドライン第2の2(1)が情報提供を求めている以上（`RULES_AND_GUIDELINES.md` §2）、
実施率が低いことを理由に製品をやめる判断はしない。

したがって**測るべきは実施率ではなく、実施していない理由**である。
「何割が通知しているか」ではなく「なぜ通知していないか」を持ち帰る。

### 通知していない理由の分類と、その意味

B群（特に質問9〜12）と、必要なら「差し支えなければ、伝えないことが多いのは
どういう相手ですか」で確かめる。

| 通知していない理由 | 意味 | 取るべき経路 |
| --- | --- | --- |
| 面倒・手間がかかる | **製品の中心。** 手間削減がそのまま効く | 散布者へ直接（ボトムアップ） |
| 誰に言えばいいか分からない | **製品の中心。** 地図で対象を出す価値が確定 | 散布者へ直接（ボトムアップ） |
| 必要だと思っていない | 製品だけでは動かない。要求する側が要る | **発注元・JA・行政から求めてもらう（トップダウン）** |
| 言うと反対される／調整が面倒 | 通知そのものへの抵抗 | §3の通知方式（一方向・調整しない）を再検討 |

### 判断

- **「面倒」「分からない」が多数** → 現行の訴求と普及経路のまま進める
- **「必要だと思っていない」が支配的** → 製品は変えない。**売り先と語り口を変える。**
  散布者への直接普及ではなく、発注元・JA・行政が求める形（契約条件、認定要件、
  補助の要件など）を作る方向へ、`BUSINESS_MODEL.md` §7の収益化順序を前倒しする
- **「反対される」が多い** → §3の通知方式そのものを見直す（§11の事業判断）

### 立ち止まる条件（やめる条件ではない）

- **5件聞いて、通知の負担も対象把握の困難も語られない**
  → 質問か相手が違う。聞き方と相手を見直してから続ける
- **10件聞いて、発注元・JA・行政のいずれにも「記録や周知を求める動き」が見えない**
  → ボトムアップもトップダウンも当面開かない。時期の見極めが必要になる。
  このとき何をするかは、門田さんの生活設計と切り離して判断できないため、
  数字だけで自動的に決めない

### 収益側の基準（製品の存続とは別の問題）

| 仮説 | 見直しを検討する条件 | 見直す対象 |
| --- | --- | --- |
| H6 | 受託事業者5者に聞いて、発注元に記録を求められた経験も、実施報告に月1時間以上かける人も**ゼロ** | 主訴求（信用材料）の順位 |
| H7 | JA・受託法人3者に聞いて、記録管理に金銭を払う意思が**ゼロ** | §5の料金と課金対象（§11の事業判断） |

これらが否定されても製品はやめない。**課金の相手と金額を変える。**

## 5. 記録の残し方

公式統計が存在しない領域なので、**聞き取りそのものが資産になる。**
毎回、その日のうちに次の形で残す。会話の記憶は3日で消える。

```
日付 / 相手の属性（個人散布者・受託事業者・JA・周辺農家）/ 地域（市町村まで）
散布規模: 面積・機体の有無・受託の有無
A群: 日程はいつ誰が決めたか
B群: 誰にどう伝えたか／伝えられない相手の有無
C群: トラブル経験・保険・報告の手間
D群: 計画書・実績報告・DIPSの実務
E群: 今の記録手段
所感: 予想と違った点（ここが一番価値がある）
次アクション: 紹介の有無、再訪の可否
```

**個人が特定される情報の扱い。**
氏名・屋号・ほ場の場所は、**本人の同意なく記録や資料に転記しない。**
第三者に話す場合は地域と属性まで（有機農家さんの件と同じ扱い）。
集計して人に見せるときは「笠間周辺の散布者◯人」の形にする。

## 6. やってはいけないこと

- **売り込む。** 相手が聞くまで製品の説明をしない。デモは求められてから
- **「違反」「守っていない」「本来は」と言う。** 責める言い方をしない
- **法令の説明を始める。** こちらが教える場ではない。聞きに来ている
- **他の人から聞いた具体的な事例を持ち出す。** 狭い地域では特定される
- **行政に話を持っていく前提を匂わせる。** 当事者が身構える
- **できないことを約束する。** 「作ります」「対応します」と言わない
- **1回で全部聞こうとする。** 45〜60分で足りなければ、また伺う

---

## 7. 進め方

1. 籾山学園長に相談し、散布に詳しい方の紹介を依頼する（D）
2. 並行して、実在の受託事業者へ直接連絡する
   （土浦市のドローンプロフェッショナルサービスは教習施設も運営しており、
   地域のオペレーター事情に最も詳しい可能性がある）
3. **1件目が終わったら、必ず質問を見直す。** 最初の1件で前提が変わることが多い
4. 5件を目安に一度立ち止まり、§4の基準に照らす
5. 当事者から得た一次情報を反映してから、行政（県・市）へ進む

**目標件数の目安。** 受託事業者は少数に集約されている想定のため5者で代表性が出る
可能性がある。個人の散布者は10人、JAは3者、周辺農家は3者。
