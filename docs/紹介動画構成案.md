# 紹介動画 構成案（となりの畑セーフティ・仮称）

作成: 2026-08-10 ／ 状態: **未確定。門田さんの確認後にキーフレーム制作へ進む**
用途: 農業関係者（散布者・ドローン受託事業者・JA・行政）に、アプリを直感的に理解してもらう
想定尺: 約60秒 ／ 16:9 ／ 1920×1080（想定であり、決定ではない）
参考: SSメンバー「地獄のICT 宣伝トレイラー構成案」の作り方、谷川智彦氏 note の 4P フレーム

---

## 0. この動画の位置づけ（先に読む）

**SSメンバーの手順は「作り方」として借り、「トーン」は反転させる。**

地獄のICTは、業務崩壊の恐怖と切迫感で引きつけるトレイラーである。その構成手順
（コンセプト → 秒割り表 → キーフレーム一覧 → ビジュアルルール → 音響方針 →
「出さないこと」リスト）は完成度が高く、そのまま流用する価値がある。

一方、**恐怖の演出をこの製品に持ち込むと事業が壊れる。** 農薬飛散の被害を劇画的に
描けば、散布者が加害者に見える。しかし本アプリの最重要の説得相手は散布者本人であり
（`BUSINESS_MODEL.md` §2 訴求点）、地元で「農薬反対の人」と見られない語り方を
方針として決めている（同 §10）。恐怖で引く動画は、この2つを同時に破壊する。

**したがって、引きの源は「恐怖」ではなく「散布者自身が感じている手間と不安」に置く。**
地獄のICTが「共感できる地獄（業務量）」で引いているのと、構造は同じである。

## 1. コンセプト

**散布する人の、朝の段取りを追う60秒。**

散布そのものは丁寧な仕事として敬意をもって描く。描く負担は「隣に知らせること」。
電話を何件もかけ、留守番電話に残し、「あの人には言ったか」を思い出せない。
その一連が、一度の投稿と、残る記録に置き換わる。

誰も責めない。危険を煽らない。「面倒が減る」と「後から説明できる」の2点に集中する。

## 2. 4P（note記事のフレーム）

| 要素 | 本動画での中身 |
| --- | --- |
| **People** | 散布する人（顔は映さない。手元・後ろ姿・作業着）。隣の農家は姿を出さず、電話の呼び出し音と受信するスマホだけで示す |
| **Places** | 夜明け前の水田、軽トラの荷台、ドローン、自宅の机、スマホ画面、アプリ画面 |
| **Plot** | 散布前に知らせる段取り → 電話と記憶に頼る負担 → アプリで通知文ができる → 1回の投稿で済み、知らせた事実が残る |
| **Purpose（CTA）** | **「実情を聞かせてください」。** 使ってもらうことではない |

**CTAをここに置く理由。** 現在は当事者ヒアリングを最優先とする段階であり
（`BUSINESS_MODEL.md` §9）、まだ実証前である。「導入してください」と締めると、
未完成のものを売り込む動画になり、SSメンバーが警告した「いきなり売り込むと
警戒される」を映像で再現することになる。**この動画のゴールは、話を聞かせてもらう
入口をつくることに限る。**

## 3. 構成（秒割り）

素材種別の凡例 — **[生]** 生成画像・生成映像／**[録]** 実画面録画／**[編]** 編集で重ねる

| 時間 | 画面 | 音・コピー | 素材 |
| --- | --- | --- | --- |
| 0–5秒 | 夜明け前の水田。無風。水面に空が映る。遠くに一台の軽トラ | 環境音のみ（鳥、風、遠くの車）。コピーなし | [生] |
| 5–9秒 | 荷台のドローンに薬液を積む手元。プロペラが静かに回り始める | プロペラの低い回転音 | [生] |
| 9–12秒 | 機体を前に、作業を止めてスマホを取り出す手 | 回転音が止む。**「まく前に、やることがある。」** | [生]＋[編] |
| 12–20秒 | 夜の机。地図と付箋、電話をかける。留守番電話。かけ直す。付箋が増える | 呼び出し音が3回重なる。**「隣に、知らせる。」** | [生]＋[編] |
| 20–24秒 | 付箋を見返す手が止まる。窓の外は暗い | 音が引く。**「あの人には、言ったか。」** | [生]＋[編] |
| 24–28秒 | 白へ転換。ロゴとコピー | 音楽が入る（明るく、静か）。**「まく前に知らせて、飛散トラブルを防ぐ。」** | [編] |
| 28–34秒 | **散布計画の登録画面**。日時・ほ場・資材が入っていく | 打鍵音。**「予定を入れると、」** | [録] |
| 34–40秒 | **圃場マップ**。航空写真の上に周辺のほ場が色分けで出る。有機・農薬不使用・収穫前が距離つきで並ぶ | **「知らせる相手が、地図の上に出る。」** | [録] |
| 40–47秒 | **近隣通知画面**。文面が自動でできている。距離・方向・理由の行が読める。「文面コピー」を押し、**人の手で LINE に貼って投稿する** | **「一件ずつの電話が、一度の投稿に。」**<br>小さく「周辺の農家は、アプリを入れる必要がありません」 | [録]＋[編] |
| 47–52秒 | **ドローン連携画面**。ログを取り込むと、飛行の軌跡と高度のグラフが出る | **「まいた記録も、同じ案件に残る。」** | [録] |
| 52–56秒 | **作業履歴**。日時・資材・面積が一覧になり、書類として出力される | **「知らせた相手も、返事も、記録に残ります。」** | [録]＋[編] |
| 56–60秒 | 白背景。サービス名、QRコード、連絡先 | 音楽が静かに終わる。**「実情を聞かせてください。」** | [編] |

**山場は 40–47秒の「電話 → 一度の投稿」。** ここが最も直感的に伝わる。
47–52秒のログ・高度は玄人（受託事業者・JA）向けの第二の山として短く置く。

## 4. 描かないこと（地獄のICTの「ネタバレ防止方針」に相当）

製品の安全境界（`CLAUDE.md`／`BUSINESS_MODEL.md` §8）を、映像で破らないための禁止事項。
**生成AIは指示しないと勝手にやるため、発注文に明記する。**

- **農薬を毒物・危険物として描かない。** 防護服の恐怖演出、飛散が画面に迫る絵、
  白い霧が住宅へ流れる絵を作らない
- **被害の映像を出さない。** 枯れた作物、体調不良、抗議、行政指導
- **農家同士の対立を描かない。** 不安の描写（鳴り続ける電話、夜の手元）はよいが、
  口論・怒鳴る・詰め寄る絵は作らない。狭い地域では、架空でも「誰かの話」に読まれる
- **監視に見える絵を作らない。** 上空から人や機体を追尾するカット、赤い標的マーカー、
  レーダー風の走査線。地図表示は「散布者が自分で周辺を確認する」視点に限る
- **ライブ位置追跡を描かない。** 将来構想であり未実装。かつ監視の絵になる（二重に不可）
- **アプリが自動送信しているように見せない。** 通知は散布者本人が文面をコピーして
  投稿する運用である。**必ず人の手が操作するカットを入れる**
- **行政・JAが許可・承認しているように見せない。** 公印、承認スタンプ、決裁の演出
- **ドローンを危険に見せない。** 低空で人へ向かう、荒れた飛行、墜落。
  適正高度で安定して飛ぶ姿だけを使う
- **実在の個人・法人・地名が特定される映像を使わない。** 表札、車両ナンバー、
  JAの看板、実在の圃場が判別できる航空写真

## 5. 必要な素材

### 5-1. 生成が必要なキーフレーム画像（前半・9点）

1. 夜明け前の水田。無風、水面に空が映る
2. 遠景の軽トラと、荷台のドローン
3. 薬液を積む手元（顔は映さない）
4. 静かに回り始めるプロペラ
5. 作業を止めてスマホを取り出す手
6. 夜の机。地図、付箋、固定電話または携帯
7. 電話をかける手元（受話器または画面の通話中表示）
8. 増えていく付箋のクローズアップ
9. 付箋を見返して手が止まる、窓の外は暗い

画像には文字を描き込まない。コピーは編集時に重ねる（地獄のICTと同じ方針）。

### 5-2. 実画面の録画ショットリスト（後半）

`HANDOFF.md` の5分デモ手順を、そのまま縮約する。

| 収録 | 画面 | 操作 | 尺 |
| --- | --- | --- | --- |
| ① | 散布計画 | 日時・ほ場・資材が入力済みの状態をゆっくりスクロール | 6秒 |
| ② | 圃場マップ | 航空写真上の周辺ほ場を表示。距離つきの一覧へ視線を送る | 6秒 |
| ③ | 近隣通知 | 自動生成された文面を見せ、**「文面コピー」をクリック** | 4秒 |
| ④ | （スマホ実写） | コピーした文面を LINE に貼り付けて投稿する手元 | 3秒 |
| ⑤ | ドローン連携 | 「同梱ログを取込」をクリック → 高度グラフが出る | 5秒 |
| ⑥ | 作業履歴 | 一覧をスクロール、CSV/PDF出力ボタンを見せる | 4秒 |

### 5-3. 収録前の必須手順

- **収録の直前に、画面左下の「サンプル読込」を必ず1回押す。**
  サンプルの日付は今日を基準に作られるが、端末に前回の日付が残る。
  押さずに録ると「今日の散布予定 0件」が動画に焼き付く
- **本番URL（`dc48deb` 反映済み）で録る。** 旧い語彙が映像に残らないようにする
- 画面パートには「デモ画面・サンプルデータ」の小さなキャプションを常時入れる
  （配布資料と同じ誠実性の運用）
- ブラウザのブックマークバー・拡張機能・個人情報を画面から消す

## 6. ビジュアルルール

- 基本色は、朝の青、水の銀、土の茶、稲の緑。**赤は警告としてのみ最小限**
  （地獄のICTの黒・深紅とは逆の設計）
- 写実寄り。劇画調の誇張、強いコントラスト、恐怖のリムライトを使わない
- 人物の顔は映さない。手元・後ろ姿・作業着で示す
- ドローンは適正高度で安定して飛ぶ姿のみ。散布がカメラへ向かう構図を作らない
- 生成画像に文字を描き込まない
- 画面録画は等倍で、実際の操作速度を大きく超えて早送りしない

---

## 7. 音響方針

- 前半（0–24秒）は音楽を使わず、環境音のみ。鳥、風、プロペラ、電話の呼び出し音
- 「あの人には、言ったか。」の直前で音を引き、一拍の無音を作る
- 24秒のコピーから、静かで明るい音楽を入れる。速くしない、盛り上げない
- 画面操作の打鍵音・クリック音は小さく残し、実在感を出す
- 最後は音楽を鳴らし切らず、静かに終える

## 8. コピー（既存の文言に揃える）

新しいスローガンを作らない。**ランディングページとチラシで使っている言葉をそのまま使い、
3つの媒体が一つの取り組みに見えるようにする。**

| 用途 | 文言 | 出典 |
| --- | --- | --- |
| メイン | まく前に知らせて、飛散トラブルを防ぐ。 | LPヒーロー |
| 導入 | まく前に、やることがある。／ 隣に、知らせる。 | 新規（本動画用） |
| 山場 | 一件ずつの電話が、一度の投稿に。 | チラシ「電話・訪問の手間を減らします」 |
| 補足 | 周辺の農家は、アプリを入れる必要がありません。 | チラシ・LP |
| 締め | 知らせた相手も、返事も、記録に残ります。 | チラシ |
| CTA | 実情を聞かせてください。 | チラシ §5 |

**避ける言い回し。**「適正に散布したことを証明」「監視」「違反」「取り締まり」、
および被害・責任を断定する表現。「証明」ではなく「記録に残る／後から説明できる」を使う。

## 9. 用途と公開範囲（**門田さんの決定が必要**）

動画には連絡先・サービス名が入り、複製されると回収できない。
現在は、記録が公に残る行動を控える方針で進めている。次のどれにするかを先に決める。

- 案A: **対面で見せるだけ**（自分の端末で再生。共有しない）
- 案B: **限定公開URL**（YouTube限定公開等。リンクを知る人だけ。LINEで送れる）
- 案C: **一般公開**（検索・推薦に載る）

**推奨は案B。** 学園長やヒアリング先に「後で見てください」と渡せる利点が大きく、
かつ不特定多数へ広がらない。案Cは、ヒアリングで手応えを得た後で判断すればよい。
なお連絡先は、動画内では**メールアドレスのみ**にし、電話番号は入れないことを勧める。
