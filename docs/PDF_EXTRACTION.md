# 自治体PDFのテキスト抽出

PDF調査時だけ参照。コマンドはリポジトリルートで実行する。

`tools/pdf-text.py`（依存パッケージなし・Python標準ライブラリのみ）。

```zsh
python3 tools/pdf-text.py 入力.pdf 出力.txt
```

**なぜ要るか。** 自治体の公開資料（総合計画・予算書・分野別計画・地域計画）はPDFでしか
出ていないことが多く、macOSには poppler が入っていない。形式は3種類ある。

1. テキスト埋め込み・Identity-H（2バイト・`<hex>`文字列）
2. テキスト埋め込み・1バイト（`(literal)`文字列）。`/Font` や `/Resources` が
   間接参照のことがある
3. 画像化（抽出不能。OCRが要る）

このスクリプトは 1 と 2 に対応する。3 は抽出文字数がほぼ0で返るので、その場で判別できる。

**事故の記録。全フォントのToUnicode CMapを1つに混ぜてはいけない。** フォントごとに同じ
コード値へ別の文字を割り当てているため、**数字が別の数字に置き換わる。** 実際に水戸市の
予算説明書で `10,852,517千円` が `32,874,737千円` と出た。半角数字だけが一律にずれる
という、気づきにくい壊れ方をする。

`tools/pdf-text.py` はフォント単位でCMapを引くため、この事故は起きない。ただし
**抽出できないページがあると数字が欠ける。金額を人に示す前に、必ず内訳の合計で検算すること。**
（例: 公設市場の「3億4,400万円＋2億500万円」が「549,000千円」と一致するか）

**出力の注意。** PDFの字送り指定により、文字間に空白が入ることがある。
キーワード検索する前に空白を詰める。

```python
import re
t = re.sub(r'\s+', '', open('出力.txt').read())
```
