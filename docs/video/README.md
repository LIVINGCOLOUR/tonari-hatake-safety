## 文言と絵の決まり

- 新しいスローガンを作らない。ランディングページ・チラシ・問題提起A4の言葉を使う。
- 不採用: 「散布する人も、まわりの人も、事実で守る。」（抽象的。2026-10-01）。締めは「飛散トラブル」を中心に言う。
- 避ける言い回し: 「法令遵守」「適法」「違反」「監視」「取り締まり」「証明」。ガイドラインは求められていることを示すだけで、守っているかを問わない。
- **夜の机で地図をなぞる場面は使わない。** 現状の運用で誰もしていない行動のため（2026-10-01）。
- 描かないもの: 農薬の恐怖演出、被害の映像、守っていない人の示唆、農家同士の対立、監視に見える絵、ライブ位置追跡、アプリの自動送信に見える絵、行政・JAの承認に見える絵、危険なドローン飛行、実在の個人・法人・地名が特定できる映像。保険・賠償には触れない。

## 作り方

```sh
docs/video/render.sh        # 2本とも。A か B を付けると片方だけ
```

- `build-promo-30s.py` が MulmoScript（`promo-60s-A.json`・`promo-30s-B.json`）を生成し、MulmoTerminal 配下の `mulmo movie` が描画する。ffmpeg が必要。1本10〜20分。
- **見せる用は `assets/video/out/final/` に時刻入りの名前で出る。** 同名で上書きするとビューアが前の版をキャッシュ再生する（2026-10-01 に発生）。`assets/video/out/` は Git 管理外。
- 全ビートを文字なし・秒数指定にしてあるので音声合成を呼ばない。変更後は `mulmo movie <台本> --estimate` で API 利用ゼロを確認する。
- 素材パスは `-b` ではなく台本ファイルの場所基準で解決される。
- 8月の75秒ドラフトは `assets/video/archive/` に移した。現行の動画ではない。
- 素材: `assets/video/` のイラスト62枚（一覧は [キーフレーム指示](../archive/動画キーフレーム指示_2026-08.md) §6-2）、`assets/video/screen/` の画面録画5本（撮り直しは [画面録画手順](../画面録画手順.md)）、`assets/video/out/clips/` は録画を尺に合わせて切り出した派生クリップ。

## 3分版（実尺4分11秒、2026-10-07 公開）

Remotion＋Veo 3.1＋Gemini TTS＋Lyria の実写風シネマ構成。台本は [script-3min.md](script-3min.md)。プロジェクトはリポジトリ直下の `video/`（run-form-coach と同じ構成）。

- **支払いは run-form-coach と同じ Vertex AI の GCP プロジェクト**（`gcloud config get-value project`、2026-10-07 時点 `runrun1010`）。無料枠の API キーは使わない。
- 声: Vertex AI の `gemini-3.8-flash-tts`、Gacrux。`video/src/lines.mjs` を直したら `npm run narration`（既にある行は飛ばす）。長さは `src/narration.json` に入り、場面の長さはそこから決まる。
- 映像: Vertex AI の `veo-3.1-generate-001`（us-central1、8秒・16:9・1080p・音なし、1本 $3.2）。指示文は `video/scripts/gen-veo.mjs` の CUTS。`npm run veo`（既にあるカットは飛ばす）。没にしたカットは `public/gen/veo/rejected/`。Fast 版と Veo 3.1 preview 系の ID はこのプロジェクトでは使えなかった。
- 音楽: Vertex AI の `lyria-002`（32秒クリップ、$0.06）。Lyria 3 系はこのプロジェクトでは使えない（要許可）。静かな曲と少し明るい曲を数本作り、Remotion 側で2秒重ねてつなぐ。`npm run music`。
- 静止画の生成は使わず、実画面は `video/public/screens/` のスクリーンショット（ログインを模擬した通常画面、1440×900）。
- 字幕: `node video/scripts/gen-vtt.mjs` が `lines.mjs` と `narration.json` から `assets/promo/intro-ja.vtt` を作る（タイミングは `timeline.ts` と同じ計算）。ナレーションや尺を変えたら作り直す。
- 組み立てと書き出し: `cd video && npm run studio` でプレビュー、`npm run render` で `video/out/` へ。**見せる用は `assets/video/out/final/` に時刻入りの名前でコピーする**（2部構成の無音版と同じ置き場。動画の置き場はここ1か所）。`video/public/gen/` と `video/out/` は Git 管理外。
- 判明した注意: Gemini TTS は「農薬」「事故」を含む文で安全フィルタに当たることがある（段落を分けて再送）。Lyria は具体的すぎる指示で「recitation」で拒否されることがある（言い換える）。Veo は農業用ドローンと指示しないと空撮用の小型機を出す。
