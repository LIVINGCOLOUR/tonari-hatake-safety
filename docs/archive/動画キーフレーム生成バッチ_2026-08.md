## 実行する人へ

### 目的

すでに8カットは揃っている。**このバッチは「編集時に選べる選択肢」を増やすためのもの。**
特にA・B・Cは、現在の構成で絵が足りていない箇所を埋める。

### 絶対に守ること

1. **すべて既存の8枚と同じ絵柄・同じ人物・同じ配色にする。**
   各プロンプトの冒頭にある「前の画像と同じ絵柄で…」を必ず含めて投げる
2. **可能なら、既存カットを生成したチャットの続きで実行する。**
   新しいチャットで始める場合は、`assets/video/baseline-keyframe-reference.png`
   を先に添付し「この絵柄・この人物・この配色で続けて描いてください」と伝える
3. **文字を一切描かせない**（看板・ロゴ・付箋の文字を含む）
4. **各プロンプトの【描かないでください】を省略しない。**
   省くと恐怖・災害・監視の絵になる
5. **既存の9枚を上書き・削除しない**
6. **git にコミットしない**（門田さんの判断。素材は未追跡のまま置く）

### 保存先と命名

`assets/video/` に、下記の指定ファイル名で保存する。
同じプロンプトから複数枚作った場合は `-a` `-b` `-c` を付ける。

例: `cut09-closing-a.png` / `cut09-closing-b.png`

### 生成枚数

**優先度Aから順に進める。** 各プロンプト3枚を目安。
枠（3時間ごと最大50枚）に達したら、そこで止めて次の枠を待つ。
**A → B → C → D → E → F → G → H の順を守る。** 途中で終わっても構わない。

### 検品

**しなくてよい。朝に人が見る。**
明らかに破綻したもの（人体が崩れている、文字が入った）だけ捨てる。

## 優先度C ── ガイドラインが挙げる配慮対象（15–23秒を支える）★新規

15–23秒は「学校、養蜂、有機のほ場。近くにあるとき…」というテロップに対し、
現在は俯瞰1枚で8秒持たせている。**個別の情景があるとリズムが作れる。**

**重要な注意。** ここは最も危険な3枚。指示を省くと恐怖の含意が出る。

- 学校 → **子供を描かない。** 描くと「子供が農薬を浴びる」という絵になる
- 養蜂 → **ミツバチのアップを描かない。** 巣箱と穏やかな風景だけ

## 優先度H ── 既存8カットの別バリエーション

枠が余ったら実施する。**既存ファイルは上書きしない。** `-v2-a` を付けて保存する。

`docs/動画キーフレーム指示.md` §4 の各カットのプロンプトを、
末尾に次の一文を足して再実行する。

```
前と少し違う構図・違う距離で描いてください。
```

保存名の例: `cut01-dawn-paddies-v2-a.png`

**カット4とカット7は不要**（動画化しない静止カットであり、既存で確定している）。

## 朝の確認用メモ

生成が終わったら、次の順で見る。

1. **A（締め）から見る。** 文字を載せる余白があるか
2. **C（学校・養蜂・有機ほ場）を厳しく見る。** 子供が描かれていないか、
   虫のアップがないか、不安な雰囲気になっていないか。
   1枚でも該当したら使わない
3. **E（俯瞰）にマーカーが入っていないか**
4. 残りは `docs/動画キーフレーム指示.md` §5 の検品リストで確認する
