# となり畑セーフティ MVP

農薬散布者が、ドローン飛行ログ、気象条件、周辺圃場ステータスを見ながら、散布前確認、近隣通知、実施後報告を行うためのフロントエンドMVPです。笠間市周辺を想定した匿名サンプルデモとして作成しています。

## 開き方

`index.html` をブラウザで開くと動作します。ログイン、DB、外部API、実SDK連携は使っていません。入力内容はブラウザの `localStorage` に保存されます。

## デプロイ先

Cloudflare Pages: https://tonari-hatake-safety.pages.dev/

## MVP機能

- トップダッシュボード
- 散布計画登録
- 圃場マップ・周辺確認
- 圃場ステータス登録
- ドローン連携モック
- サンプル飛行ログ取込
- 近隣通知文生成
- 散布前チェックリスト
- 気象・風向風速メモ
- Open-Meteoによる気象予報の自動取得
- 実施後報告
- PDF印刷用ビュー
- 地域管理者向け一覧
- 実証ルール案設定
- 確認完了度表示
- 匿名サンプルデータ

## 設計方針

法的な判定や原因断定ではなく、散布前後の確認状況を「未確認」「要確認」「記録済み」として扱います。散布者、周辺農家、JA、自治体が同じ情報を確認できることを優先した検証用MVPです。

## 今回の改良点

- 目的を「被害記録」から「農薬飛散被害の未然防止」に変更
- デモ地域を「笠間市周辺を想定した実証デモ」に変更
- 実在しそうな氏名、電話番号、旧地域名を匿名サンプルへ変更
- 圃場ごとの農薬使用状況、有機JAS、通知希望、収穫時期、育苗・水路近接などを登録
- ドローン機体、機体登録記号、操縦者、散布装置、予定高度、予定速度を散布計画に追加
- 飛行ルート、散布ON/OFF、高度要確認点、予定範囲外飛行をサンプルログで表示
- 予報と実測の風、最大瞬間風速、気温、湿度、降雨予報、測定方法、測定者を記録
- 笠間市周辺デモ地点の緯度経度からOpen-Meteoの予報値を取得
- 役割選択、散布者向け作業フロー、有機農家向け圃場編集、通知返信を追加
- 実施後報告にドローンログ概要、高度要確認区間、予定範囲外飛行、報告分類を追加
- 評価ラベルを「確認完了度」に統一
- 運用条件を「実証ルール案」に統一

## V1で未実装のもの

実認証、バックエンドDB、LINE送信、DIPS連携、ドローンメーカーSDK、地番・圃場台帳連携、実GIS編集、権限管理は未実装です。気象情報はOpen-Meteoの予報値を取得しますが、散布直前の現地実測の代替ではありません。

## 気象自動取得

`気象メモ` 画面の `気象情報を自動取得` から、Open-Meteo Forecast APIで予報風向、予報風速、最大瞬間風速、気温、湿度、降雨見込みを取得します。通信できない場合は、手入力の値で継続できます。
